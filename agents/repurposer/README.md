**One piece of content → many platform-tailored variants** for TanSri | Millionaires.

- **Role:** Content repurposing / distribution
- **Platforms:** TikTok · Instagram Reels · YouTube Shorts · Facebook · Threads · X
- **Status:** 🟡 Stub — behavior defined; routes variants to the posting agents.
- **Skill:** [`.claude/skills/repurposer/SKILL.md`](../../.claude/skills/repurposer/SKILL.md)

## Task
Takes a source video, script, or Watcher rebuild and produces ready-to-post cuts,
captions, and hashtags tuned to each platform — then hands each variant to the
right posting agent.

## Abilities
- Platform-tuned hooks (length + culture aware)
- Caption + hashtag set per platform (no identical tag walls)
- Cut spec (length + aspect ratio)
- Routing to 🐾 Black Panther / 🔵 Blue Hulk / 🟢 Hulk / 🗓️ Buffer

## Principle
Repurpose the *lesson*, re-skin the *packaging*. One core idea across every
variant; real chart footage stays real.

Feeds into: all posting agents. Feeds from: 👁️ The Watcher.
