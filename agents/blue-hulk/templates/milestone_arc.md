# Template: Milestone / Growth Arc — ⚠️ USE WITH EXTREME CAUTION

The research verified this format (small number → documented climb → big number) as highly
shareable — and directly tied to an FTC enforcement action against one of the creators studied.
It is the highest-risk framework in the playbook. Default answer: don't. Use only when ALL of
the gate conditions below hold.

## Gate conditions (all required)

- [ ] The numbers are REAL, the operator's own, and independently verifiable
- [ ] The timeline is complete — including drawdowns and losing periods, not a cherry-picked run
- [ ] Explicit results-not-typical framing INSIDE the story (not a footnote disclaimer)
- [ ] The resolution is process/discipline, not the money
- [ ] No implied "you can too" — the reader is invited to the process, never to the outcome

## Structure (only if gated through)

```
[Hook — the starting number and its date. Small, specific, honest.]

[The climb — milestones WITH the setbacks in between. The drawdown month goes in. That's what
separates this from the pattern regulators acted on.]

[The cost — what it took: hours, losses along the way, what was given up.]

[Results-not-typical, in voice — "This took N years and most people who try this lose money.
Both halves of that sentence are true."]

[The lesson — the process element that mattered, transferable.]

[CTA — question about the reader's process, never about their goals/dreams.]
```

Notes:
- If any gate condition fails, use `origin_story_arc.md` (no numbers) or
  `third_party_war_story.md` (documented, attributed) instead — both deliver the same emotional
  payload without the regulatory/credibility exposure.
