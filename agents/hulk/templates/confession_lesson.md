# Template: Confession → Lesson

Use when: sharing a loss or mistake to build credibility before giving advice. Use sparingly —
it works because it's rare, not because it's the default.

```
[Plain statement of the loss/mistake — real number if available, or clearly illustrative]

[What caused it — one line, no excuses]

[The rule/lesson that would have prevented it, stated for the reader to use]
```

Example shape:
```
Lost most of a position chasing a breakout that wasn't real.

No confirmation, no plan — just FOMO.

Now: no entry without a defined invalidation level, full stop.
```

Notes:
- Never fabricate a specific loss presented as real personal history — use a real figure if the
  operator supplies one, otherwise keep it generic enough to clearly read as illustrative.
- The lesson must be genuinely useful, not just a moral tacked on for effect.
