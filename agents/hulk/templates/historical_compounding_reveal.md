# Template: Historical-Proof Compounding Reveal

Use when: illustrating a principle (patience, compounding, cycle timing) using real, public,
verifiable historical data — a stock's split/dividend history, a coin's cycle history — rather
than the poster's own trades. No personal risk disclosure needed since it's documented fact.

```
[Title line stating the principle, e.g. "Sometimes one position is all it takes"]

[Asset] in [start year]: [starting value/quantity]
[Year]: [event — split, bonus, cycle milestone] → [running value]
[Year]: [event] → [running value]
...
[Latest year]: [current value] — total: [dramatic terminal figure]
```

Example shape:
```
Patience compounds. Discipline compounds harder.

$1,000 in [asset], [start year].
[Milestone year]: [event] → $[value]
[Milestone year]: [event] → $[value]
[Latest year]: $[value] — a [X]x return over [N] years.
```

Notes:
- Every figure must be real and independently verifiable — this template's entire credibility
  rests on factual accuracy. Do not use invented or approximate numbers presented as exact.
- Keep the itemized list dense and dated; the specificity is what makes it credible and
  shareable.
