# Template: Audience Question / Poll

Use when: you want pure engagement with no informational payload — the audience supplies the
content via replies. Use sparingly relative to value-first posts; it works because it's a change
of pace, not because it's the default.

```
[Direct question about a live market situation, tied to real current conditions]
```

Examples:
```
What's the one trade you're avoiding right now even though everyone's talking about it?
```
```
Are you buying this dip or waiting it out?
```

Notes:
- Must be genuinely answerable in one line by a reader — avoid anything that requires research.
- Tie it to something actually happening in the market, not a generic evergreen question, so it
  reads as timely rather than filler.
