# Template: Standalone Aphorism / Principle

Use when: daily-cadence, low-production-cost posting. One evergreen trading/finance principle,
no elaboration, no specific prediction (so it can't be "wrong").

```
[One complete, quotable sentence about trading, risk, or markets.]
```

Good source shapes:
- "If you [common mistake], you're not [doing X] — you're [doing Y]."
- "Your biggest risk isn't [obvious thing], it's [less obvious thing]."
- A single hard-won rule stated flatly, no hedging.

Example:
```
The stop-loss you moved "just this once" is the one that mattered.
```

Notes:
- No elaboration, no thread — the whole idea lives in one line.
- Should be true and generalizable, not tied to a specific real trade unless illustrative and
  clearly generic.
