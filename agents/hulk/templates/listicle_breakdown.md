# Template: Listicle / Bulleted Breakdown

Use when: covering multiple data points, rules, or a portfolio/allocation snapshot. The most
format-agnostic pattern across every creator studied.

```
[One-line intro or hook] 👇

• [Item 1]: [value/detail]
• [Item 2]: [value/detail]
• [Item 3]: [value/detail]
...

[Optional one-line close or CTA]
```

Example shape (trending/movers):
```
What's moving today 👇

• [Ticker/asset]: [+/-X%] — [one-word reason]
• [Ticker/asset]: [+/-X%] — [one-word reason]
• [Ticker/asset]: [+/-X%] — [one-word reason]
```

Example shape (rules/mistakes):
```
[N] mistakes that blow up small accounts:

1) [Mistake]
2) [Mistake]
3) [Mistake]
```

Notes:
- Keep each bullet scannable — a phrase, not a sentence.
- Only add a link-out CTA if there's a genuine destination (e.g. a chart); otherwise leave it off.
