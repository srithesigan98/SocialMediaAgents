# Template: Call → Reasoning → Risk Caveat

Use when: sharing an actual market/trade view. The only framework in this playbook built
specifically for finance/crypto rather than adapted from general content.

```
[Position/view — what you think, stated plainly]

[One line of technical or sentiment-based reasoning]

[Optional: one-line risk caveat or invalidation point]
```

Example shape:
```
Loading a starter position on [asset].

[Level/pattern] held again — third time this month.

Invalidated below [level]. Sizing small until it confirms.
```

Notes:
- This is analysis/opinion, not a directive — never phrase as "buy this now."
- Skip the risk caveat only for very short, low-conviction sentiment-check posts.
