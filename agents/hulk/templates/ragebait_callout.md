# Template: Ragebait / Hypocrisy Callout

Source: @movanniish (see `../playbook/creator-research.md` §5). Use when the goal is reply/
quote-post volume specifically, not agreement — this is a deliberate spice, not the default
register. See `../playbook/content-playbook.md` framework 8 for the full writeup and guardrail.

## Variant A: hypocrisy-callout escalation

Three beats showing how the same critic's framing of a behavior shifts as the outcome changes,
closed with a wry, dismissive one-liner.

```
When [outcome A, negative]: "[critic's dismissive line]"
When [outcome B, mild positive]: "[critic's grudging line]"
When [outcome C, big positive]: "[critic's sudden interest line]"

[Wry closing line pointing out nothing about the behavior/risk actually changed.]
```

Example:
```
When I lost money: "dude, you're just gambling."
When I made some money: "damn, you got really lucky."
When I became a millionaire: "I have $500 to invest, can you help me?"

Funny how that works.
```

## Variant B: blunt unhedged command

A flat, often all-caps, zero-reasoning directive-shaped opinion aimed at a *behavior* — the
bluntness is the hook, not an argument you're making. Never aim this at a specific real asset or
ticker (that becomes a buy/sell call, which is out of scope — see guardrail).

```
[ALL-CAPS OR FLAT COMMAND AIMED AT A BEHAVIOR].

[One short line, optional, that reframes why the behavior is the real problem.]
```

Example:
```
STOP AVERAGING DOWN ON A STOCK YOU HAVEN'T RESEARCHED IN SIX MONTHS.

That's not conviction. That's a sunk cost with extra steps.
```

Notes:
- Reserve for behavior, psychology, or industry-hypocrisy takes — never a specific buy/sell
  directive on a real asset ("dump gold now" stays out of scope for Hulk even though it's the
  source creator's own most-viral-shaped post).
- No fabricated personal claims — the "I" in variant A must stay illustrative/generic unless a
  real, verifiable figure is supplied.
- Use sparingly. Every post in this register spends some credibility; the rest of the playbook
  is built on Hulk *not* reading like every other engagement-farming account.
