# Framework: Location First

For listings whose `highlight` is about access, transit, or surroundings.

Line 1 — the location fact as the hook ("4 minutes to the LRT. Covered walkway the whole way.")
Line 2 — who that actually suits (renter profile / commuter / family).
Line 3 — the property + price.
Line 4 — the CTA line, verbatim.
