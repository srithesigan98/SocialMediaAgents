# Social Media Agents

This folder holds AI social media agents built for automated content creation and posting.
Each agent lives in its own subfolder with a persona, a content playbook, reusable templates,
and (where applicable) scripts for drafting/posting content.

## Agents

- [`hulk/`](./hulk) — Threads content agent focused exclusively on finance, trading, the stock
  market, and cryptocurrency.
- [`blue-hulk/`](./blue-hulk) — Facebook content agent, same topic scope as Hulk, built for
  longer-form storytelling, stronger CTAs, and poster/graphic generation via Canva. 🚧 In
  progress.
