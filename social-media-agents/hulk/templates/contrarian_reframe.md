# Template: Contrarian Reframe

Use when: the crowd consensus (bullish euphoria or bearish panic) is worth pushing back on, or a
common assumption deserves subversion.

```
[Expected/obvious take] isn't [the real risk/point].

[The actual risk/point] is.
```

or the conditional form:

```
If you want [outcome everyone wants], [counterintuitive action] — not [the obvious action].
```

Examples:
```
The risk right now isn't that price drops. It's that everyone's positioned for it not to.
```
```
If you want to survive a drawdown, size the position before you're in it — not after.
```

## Variant: false-binary rejection

Use when there are two loud, opposing consensus camps and neither is right. Stage both, reject
both, then present a third, data-backed position.

```
Everyone's either saying [camp A] or [camp B]. Both are wrong.

[The actual data/structure/pattern] says [your real position].

[One line of concrete evidence/reasoning].
```

Example:
```
Everyone's either screaming "the bottom is in" or "it's dead." Both are wrong.
Cycles don't care which one feels better to you.
This one's tracking the last cycle at a 0.9+ correlation — we're roughly two-thirds through.
```

Notes:
- Must be substantively true, not contrarian for its own sake — the reasoning has to hold up if
  someone pushes back in the replies.
- Works best when timed against visible crowd sentiment (euphoria, panic, obvious consensus).
- For the false-binary variant, only use a specific data claim (correlation, %, timeframe) you
  can actually back up — never fabricate a precise-sounding statistic.
